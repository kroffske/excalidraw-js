# Расчёт карточек в браузере

Подэкспорт `@kroffske/excalidraw-diagrams/card` содержит чистые `fitCard` / `fitText`, их прежние псевдонимы и TypeScript-типы. Он не импортирует `Scene`, файловую систему, DOM или движки компоновки. Потребитель получает размеры и относительные координаты, затем создаёт свои элементы.

```ts
import { fitCard } from '@kroffske/excalidraw-diagrams/card';
const card = fitCard({
  id: 'adapter', title: 'Адаптер сцены',
  rows: [{ id: 'description', text: 'Преобразует модель в элементы.', size: 20, minSize: 20 }],
  width: 320, padding: 20, titleSize: 24, titleMinSize: 24,
  titleMaxLines: Infinity, metrics: 'helvetica', lineHeight: 1.25,
  strict: true,
});
```

`metrics: 'helvetica'` использует общий измеритель `graph-layout/text` с поддержкой кириллицы. Значение по умолчанию `approximate` сохраняет прежнюю оценку ширины. `lineHeight` явно задаёт множитель высоты строки; прежнее значение по умолчанию — `1.22`. Указание семейства шрифта само по себе не переключает метрики. Для соответствия расчёту потребитель должен использовать тот же шрифт и интервал при отображении.

`title`, `rows` и `badge` содержат расчёт текста, координаты, доступную ширину и исходные строки. `height` растёт по содержимому. Ограничения `maxLines`, `minSize`, `overflow`, `maxHeight` и `strict` сохраняют прежний смысл. `strict` отклоняет карточку, если даже минимальный символ не помещается в доступную ширину. Отрицательные или нулевые ширины отклоняются.

Библиотека не понимает роли Map, типы схем, статусы, локализацию и правила сокращения текста. Их задаёт потребитель. Корневые Node API `fitCard`, `nodeCard`, `fitText`, `textBox` используют этот же расчёт; прежние импорты и значения по умолчанию сохранены.
